## 2. Application : Gestion de l'État

Cette application permet de mettre en pratique les concepts fondamentaux de la gestion de l'état en React, notamment useState, useEffect, la gestion des événements, les formulaires, les listes de tâches et la modification des données d'un objet utilisateur.
